# 12. 表示言語の用語集（日本語と英語の対応）

> [仕様書の目次](README.md)

画面の表示言語を日本語と英語で切り替える（#487）にあたり、画面に出る用語の英語の訳を先に決めておく（#488）。画面ごとに分けて訳すと同じ言葉の訳がぶれるため、訳は必ずこの表に合わせる。

## 12.1 決めごと

- 日本語の用語の正本は [README.md](README.md) の 3 節。この章はそれに英語を対応させるだけで、日本語の用語は決めない（新しい用語は 3 節に足してから、ここに足す）
- 辞書（#487）のキー名は、この表の英語の訳をもとにそろえる。同じ用語は、どの画面でも同じキーの訳を使う
- 英語は文頭だけ大文字にする（Sentence case。「Real-time summary」）。固有名（Whisper・Ollama・LM Studio・Tailscale・HuggingFace・Remote Whisper）はそのまま
- 「（仮）」と付けた訳は、匠の確認がまだのもの。確認が取れたら外す（12.4 節）
- 日本語の使い分け（「セッション」は録音にだけ使う、「版」と「バージョン」を分ける、など）は英語でも保つ。1 つの日本語に 1 つの英語、1 つの英語に 1 つの日本語を対応させ、同じ英語を別の意味に使わない

## 12.3 画面から洗い出した文言との対応

`web/src` の画面の文言（`features/`・`components/`・`app/`）から用語を洗い出し、12.2 節の表にないものは次の方針で訳す。

- 状態の文言（「〜しています…」）は進行形の英語（「Connecting…」）にし、末尾の「…」は日本語の「…」と同じく残す
- 「〜できませんでした」は「Couldn't …」、「〜が見つかりません」は「… not found」にする
- 数と単位（「3 分」「12 秒」）は数字と略した単位（「3 min」「12 sec」。min・sec と略して統一する。「日」は day(s)）に、「N 件」は「N items」にする。複数形はキーごとに用意する
- 丁寧な呼びかけ（「〜してください」）は命令形（「Choose a project」）にし、「Please」は付けない

## 12.4 仮の訳の確認

（仮）を付けた訳のうち迷うものは、案を並べて #488 で匠に聞いた。返事が来たら、ここと 12.2 節の（仮）を外して決まった訳にそろえる。

| 用語 | 仮の訳 | 別の案 |
|---|---|---|
| 浄書済み文字起こし / 浄書 | Polished transcript / Polish | Final transcript、Refined transcript、Cleaned-up transcript |
| 話者分け | Speaker labeling | Speaker identification、Diarization |
| 音源 | Audio source | Input、Source |
| 要約度 | Summary detail level | Summary level、Detail level |
| 版（再生成の結果） | Revision | Version（アプリの Version とぶつかるので、文書の版だけ Revision）、Variant |
| 中間サーバー | Relay | Relay server、Proxy |
| クラウド版・セルフホスト版 | Cloud edition / Self-hosted edition | Cloud version、Cloud |
| 用語リスト | Term list | Vocabulary、Hotwords、Glossary |
| 参考資料 | Reference materials | Reference set、Materials |
| 全体設定 | Global settings | Settings、App settings |
