## 1. 目的と範囲

クライアントで録音した音声をホストに送り、疑似リアルタイムで文字起こしする。録音中は数分おきにリアルタイム要約を作り、録音が終わったら時間をかけて最終要約を作る。参考資料ファイルから用語リストとコンテキストを作り、文字起こしと要約の精度を上げる。

### 今回の範囲に入れないもの（検討事項）

- 認証と、外部に公開するときの安全対策（7.4 節を参照）
- セッションの削除・名前の変更
- ディレクトリをまたいで時系列で並べる履歴表示
- 画像・Notion・Web サイトを参考資料ファイルとして読み込むこと
- 話者分け（後処理で WhisperX などを使う想定）
- 日本語以外の言語

## 2. 基本方針

1. **録音は AI に依存させない。** Whisper や Ollama が落ちたり読み込み中だったりしても、音声の受信と保存は続ける。文字起こしと要約は録音ファイルから後で作り直せる。
2. **GPU は必要なときだけ使う。** サーバーはいつでも録音を受け付けるが、モデルは録音が始まったときに読み込み、使わなくなったら解放する。
3. **データベースは使わない。** データはすべてファイルとして置く。正本は各ファイルとそのフロントマターで、`project.json` は正本から作り直せる索引として扱う。
4. **フロントマターはシステムが書く。** 日時・モデル・対応するファイルなど、システムが知っている情報は LLM に書かせない。
5. **ファイルの読み書きはサーバー側で行う。** クライアントはサーバーの API を通してしかファイルを扱わない。

## 3. 用語

| 用語 | 意味 |
|---|---|
| プロジェクト | ホスト上のディレクトリ1つ。セッションと参考資料を持つ |
| セッション | 1回の録音とその成果物。「セッション」は録音にだけ使う |
| ログインセッション | クラウド版のログインの状態（`web_sessions`） |
| 新規セッション画面 | サイドバーの ＋ で開く、まだ録音していない画面 |
| 参考資料 | 選んだ参考資料ファイルの組と、そこから作った用語リスト・コンテキストのまとまり |
| 参考資料ファイル | 参考資料の元にするファイル（.md・.txt・.html・.pdf） |
| 用語リスト | Whisper に hotwords として渡す語の一覧。内訳は「用語リスト（資料抽出）」と「用語リスト（文字起こし抽出）」 |
| 用語リスト（資料抽出） | 参考資料ファイルから作った用語（`hotwords-<ID>.md`） |
| 用語リスト（文字起こし抽出） | 録音中に文字起こしから拾った語（`pickedTerms`）。セッションごと、× で消せる |
| コンテキスト | 参考資料ファイルから抜き出した、Ollama に渡す情報 |
| 文字起こし | 総称。リアルタイム文字起こしと浄書済み文字起こしの両方を指す |
| リアルタイム文字起こし | 録音中にチャンクごとに流れてくる文字起こし（`transcript-<ID>.md`） |
| 浄書済み文字起こし | 録音後に、録音全体から作り直した文字起こし（文ごとの行・話者つき。6.9 節） |
| 浄書（する） | 浄書済み文字起こしを作る処理。話者分けを含む |
| 話者分け | 誰がいつ話したかを出し、文に話者を付けること |
| チャンク | リアルタイム文字起こしの単位（無音か 25 秒ごと） |
| 要約区間 | 要約の区切り（行の区切りで約 4000 文字ごと） |
| リアルタイム要約 | 録音中に数分おきに作る要約。思考モードはオフ |
| 最終要約 | 録音後に作る要約。思考モードはオン。全体概要と要約詳細からなる |
| 全体概要 | 最終要約の先頭の短い箇条書き |
| 要約詳細 | 最終要約の、要約区間ごとの要約（一度に収まるときは要約そのもの） |
| 要約度 | 要約の細かさ（1〜5、既定 3）。リアルタイム要約・全体概要・要約詳細で別々に設定する |
| 再生成 | 要約や浄書済み文字起こしを、今の全体設定で作り直すこと |
| 版 | 再生成でできた、それぞれの結果（「2 つ目の版」）。アプリ・画面・規約のものは「バージョン」と呼ぶ |
| ホスト | GPU を持ち、`server/` が動く PC。ダイレクト版・クラウド版の両方でこう呼ぶ |
| クライアント | 画面（`web/`）を開いているブラウザ（PC・スマホ・PWA） |
| 中間サーバー | クラウド版で、クライアントとホストのあいだを中継する Worker（`relay/`）。Cloudflare Tunnel と cloudflared は「トンネル」と呼び、中間サーバーには含めない |
| クラウド版 | 中間サーバーを通して使う形。カタカナで書き、コード・設定の値は `cloud` |
| ダイレクト版 | LAN・Tailscale でホストに直接つなぐ形。カタカナで書き、コード・設定の値は `direct` |
| サイドバー | 左の、プロジェクトとセッションの一覧（Ctrl+B） |
| 全体設定 | `setting.json` の中身 |
| 設定モーダル | 全体設定を開く画面 |
| 簡易設定 | 右上の、モデル・要約度・参考資料を選ぶところ。参考資料メニューを含む |
| 参考資料メニュー | 簡易設定の中の、参考資料を選ぶ画面 |
| マイクボタン | 中央下の大きいボタン。録音開始・一時停止／再開・＋・「録音中のセッションに戻る」に変わる |
| 録音停止ボタン | 録音を終える、マイクボタンの横の小さいボタン |
| 切り替えタブ | 上部の「文字起こし／要約」の切り替え |
| GPU インジケータ | 上のバーの左の、GPU の状態の表示 |
| 常駐アイコン | Windows のタスクトレイと Mac のメニューバーのアイコン |

- 使う用語には「の」を入れない（「〜の画面」ではなく「〜画面」とする）。
- 表にない言葉で、上の名前とまぎらわしいものが出てきたら、決めてから使う。
